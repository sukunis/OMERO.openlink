# OMERO.openlink  <img src="/images/icon.png?raw=true" width="70" height="70">   

**OMERO.openlink** is an OMERO.web plugin suite designed to create secure, openly accessible URLs (raw file access links) for your OMERO data. It integrates with a batch utility to facilitate streamlined data retrieval using `curl`.


## Main application:
* **Pre-Publication Data Access:** Provide reviewers with early, stable access to datasets via direct URLs.
* **Data Aggregation:** Bundle related data from multiple groups, projects, or datasets into a single accessible package.
* **High-Speed Retrieval:** Enables fast, bulk download of large datasets.
* **External Collaboration:** Allows external collaborators to easily access specific, permitted data via stable URLs.


## Example: 
**Provide data used in a publication**

Winkelmann, H., Richter, C. P., Eising, J., Piehler, J., & Kurre, R. (2024). Correlative single-molecule and structured illumination microscopy of fast dynamics at the plasma membrane. Nat. Commun., 15(5813), 1–19. [doi: 10.1038/s41467-024-49876-9](https://doi.org/10.1038/s41467-024-49876-9)

## Architecture:

<img src="/images/OpenLink.png?raw=true" height="450" > 

OMERO.openlink is composed of two components:

### 1. `Create_OpenLink.py` (Generation Component)
This server-side Python script is responsible for generating soft links to your data within OMERO and creating a companion batch file (`.curl`) for bulk download.

**Access Control:** You can share only your own data or the data of a non-private group if you are the owner of this group (the owner of the data will be informed by mail).

<img src="/images/scriptGUI.png?raw=true" height="450" alt="Screenshot of the script generation interface">  

>**NOTE:** If you require an alternative download manager (instead of `curl`), you can customize the generated commands directly within the Python script.

### 2. `omero-openlink` (Visualization/Interface Component)
This is the OMERO.web plugin that inventories the links generated by the script via the Nginx server. It provides the corresponding `curl` command directly within the OMERO interface, allowing users to initiate downloads in their shell. The plugin also enables the deletion of generated link areas through the OMERO.web UI.
